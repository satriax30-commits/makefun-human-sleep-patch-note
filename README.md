# makefun-human-sleep-patch-note

Entry for **Fix Human Sleep: Funniest Patch Note** on make.fun.

A Node 22 program (stdlib only, deterministic, no network) that writes one
single-line patch note announcing human sleep has been fixed, in genuine
terse changelog voice, to `/output/entry.txt`:

> Fixed: humans no longer wake at 3 AM to replay an embarrassing moment from 2014; the replay has been rescheduled to never.

Run it with:

```sh
node main.ts
```

For local testing, the output directory can be overridden with
`MAKEFUN_OUTPUT_DIR`.
